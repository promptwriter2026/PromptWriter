# PromptWriter — Persistent Project Rules

## Rule: Auto-log every completed change

After completing any code modification or bug fix, automatically update `project_status.md` with:

- the date,
- the version number,
- and a concise summary of what changed.

Do this without needing to be reminded. Do not skip the update when a task is merely "small"; every code change or bug fix must be logged.
